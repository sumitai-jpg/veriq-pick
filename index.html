チャットの答えを、その場で確かめる

ChatGPTの返答を選択して1クリック。Veriqが出典を読んで、主張ごとに裏付けを返します。無料プランのままで使えます。

PC（Chrome・Safari・Edge）

下のボタンをブックマークバーにドラッグしてください。

Veriqで検証

使い方は3手順。

  1. ChatGPTの返答をマウスで選択する
  2. ブックマークバーの「Veriqで検証」を押す
  3. パネルが出るので「検証する」。初回だけAPIキーを聞かれます

iPhone（ショートカット）

ChatGPTアプリの返答を長押しでコピーし、ショートカットを実行します。

  1. ショートカット.app →「＋」→ 新しいショートカット
  2. 「クリップボードから取得」を追加
  3. 「URLの内容を取得」を追加。URLに https://solene-0e598278.base44.app/functions/veriqVerify
  4. 同じアクションの詳細を開き、方法を POST、本文を JSON にして
    項目 text に「クリップボード」の変数を入れる
  5. ヘッダに Authorization / Bearer 自分のキー と Content-Type / application/json を追加
  6. 「辞書から値を取得」で verdict を取り、「結果を表示」

ホーム画面に置けば、コピー→アイコン→判定まで2タップ。

キーについて

キーは初回に入力すると、その端末のブラウザにだけ保存されます。OpenAIには渡りません。作り直すときは キー発行ページ へ。

ChatGPTのページは外部スクリプトの読み込みを制限しているため、この仕組みはコードをブックマークに直接持たせています。だから通信先はVeriqだけで、ページ側の制限に引っかかりません。
